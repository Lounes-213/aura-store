# 👑 AURA Haute Couture — متجر الأزياء الراقية

مشروع متجر إلكتروني متكامل فاخر مبني بأحدث معايير **UI/UX Pro Max** لتجارة الأزياء والموضة الراقية (Luxury E-commerce).

---

## 📁 الهيكل البرمجي (Clean Architecture)

```
C:\Prog Web\Aura Store\
│
├── index.html           # الصفحة الرئيسية (Hero, Value Ribbon, Categories, Featured Products)
├── catalog.html         # الكتالوج الكامل مع فلاتر حية بالقسم، الجنس، والسعر والبحث الفوري
├── product.html         # صفحة تفاصيل المنتج، معرض صور، اختيار الألوان والمقاسات
├── checkout.html        # نافذة الدفع وإتمام الطلب وحساب التوصيل لـ 58 ولاية
├── about.html           # قصة الدار والحرفية اليدوية وقيم العلامة
│
├── css/
│   └── main.css         # Design Tokens, Dark/Light Mode, Grid System, Buttons, Drawers
│
├── js/
│   └── store.js         # محرك المتجر: السلة (Cart Drawer), التخزين المحلي، تبديل الثيم
│
├── data/
│   └── products.json    # قاعدة بيانات المنتجات مع الصور، الأسعار بالدينار (DZD)، والمقاسات
│
└── assets/
    ├── icons/
    │   ├── logo.svg       # الشعار الملكي الأيقوني (Dark version)
    │   └── logo-light.svg # الشعار المذهب للشاشات الداكنة
    └── images/            # وسائط وتصاميم المتجر
```

## 🎨 مواصفات الـ Design System المعتمد

- **النمط**: Liquid Glass & Luxury Minimalism.
- **الألوان**:
  - `Primary`: `#1C1917` (أسود فحمي فاخر)
  - `Accent / CTA`: `#C5A059` (ذهب عيار 24 بلمعان ناعم)
  - `Background`: `#FBF9F5` (عاجي دافئ مريح للعين)
  - `Dark Mode`: دعم كامل للنظام الداكن مع حفظ التفضيل في المتصفح.
- **الخطوط**:
  - العناوين الفاخرة: `Cormorant Garamond`
  - النصوص العربية: `Cairo`
  - الأرقام والأسعار: `JetBrains Mono`

---

## ⚡ الميزات التفاعلية المدمجة

1. **حقيبة تسوق عائمة (Slide-in Cart Drawer)** مع عداد مباشر وحساب فوري للمجموع.
2. **نظام تبديل المظهر (Dark / Light Theme)** بزر واحد في الـ Header.
3. **فلترة فورية في الكتالوج** بالقسم والبحث السريع دون إعادة تحميل الصفحة.
4. **شحن مدروس للجزائر (58 ولاية)** مع حساب فوري لتكلفة التوصيل وميزة الشحن المجاني للطلبات الكبرى.
5. **استجابة كاملة (100% Responsive)** على شاشات الهواتف، الأجهزة اللوحية، وشاشات الـ 4K.
